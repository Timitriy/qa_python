## Покрытые сценарии (15 тест-кейсов)

| №  | Метод / сценарий                            | Что проверяем                           |
|----|---------------------------------------------|-----------------------------------------|
| 1  | add_new_book — длина **1** символ           | валидное добавление                     |
| 2  | add_new_book — длина **40** символов        | валидное добавление                     |
| 3  | add_new_book — пустая строка                | должны отклонить                        |
| 4  | add_new_book — 41 символ                    | должны отклонить                        |
| 5  | add_new_book — дубликат                     | в словаре остаётся 1 запись             |
| 6  | set_book_genre — валидный жанр              | жанр устанавливается                    |
| 7  | set_book_genre — жанр вне списка            | жанр не меняется                        |
| 8  | get_book_genre                              | возвращается корректный жанр            |
| 9  | get_books_with_specific_genre — **есть**    | список книг по жанру                    |
| 10 | get_books_with_specific_genre — **нет**     | возвращается пустой список              |
| 11 | get_books_genre                             | возвращается полный словарь             |
| 12 | get_books_for_children                      | книги 18+ не попадают в выдачу          |
| 13 | add_book_in_favorites                       | добавление без дублей                   |
| 14 | delete_book_from_favorites                  | удаление из избранного                  |
| 15 | get_list_of_favorites_books                 | актуальный список избранных             |
